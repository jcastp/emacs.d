Minibuffer completion (vertico, prescient, consult, marginalia, embark,
orderless) and in-buffer completion (corfu, cape).  Loaded before the personal
and work modules, both of which call into consult at load time.

** consult
Completion from a list of candidates, and has enhanced commands.
https://github.com/minad/consult

  (use-package consult

           ;; misc commands

           ("M-g i" . consult-imenu-multi)
           ("M-g h" . consult-org-heading)
           ("M-g a" . consult-org-agenda)

** embark
This package provides a sort of right-click contextual menu for Emacs, accessed through the embark-act command (which you should bind to a convenient key), offering you relevant actions to use on a target determined by the context:
https://github.com/oantolin/embark/
#+begin_src emacs-lisp
  (use-package embark
    :ensure t
    :bind
    (("C-." . embark-act)
     ("C-h B" . embark-bindings))

    :init
    ;; Optionally replace the key help with a completing-read interface
    (setq prefix-help-command #'embark-prefix-help-command)

    :config
    ;; Hide the mode line of the Embark live/completions buffers
    (add-to-list 'display-buffer-alist
                 '("\\`\\*Embark Collect \\(Live\\|Completions\\)\\*"
                   nil
                   (window-parameters (mode-line-format . none)))))

  ;; Consult users will also want the embark-consult package.
  (use-package embark-consult
    :ensure t
    :after (embark consult)
    :demand t ; only necessary if you have the hook below
    ;; if you want to have consult previews as you move around an
    ;; auto-updating embark collect buffer
    :hook
    (embark-collect-mode . consult-preview-at-point-mode))
#+end_src

** in-buffer completion
Corfu shows completion-at-point candidates in an in-buffer overlay
popup instead of the =*Completions*= buffer
(=tab-always-indent 'complete= in the minibuffer section above still
triggers completion on TAB; corfu just changes how results are
displayed). It reuses the =orderless= completion style already set
above, so filtering works the same as in the minibuffer.

Sources feeding the popup:
- =dabbrev-capf= (built-in since Emacs 28) for words already present
  in open buffers, in any language.
- =cape-dict= for words that have never been typed anywhere, drawn
  from the =hunspell= word list *of the buffer's language*.
  Hunspell's =.dic= files carry affix flags (e.g. =dog/S=) that
  cape-dict must not show as candidates, so a plain, flag-stripped
  word list is generated once into =my-data-dir= and reused on
  subsequent starts.

  Which list is used follows =jinx-languages=, the same variable that
  drives spellchecking (see the spelling section in =00-core=), so an
  English file offers only English candidates and a file marked
  =#+language: es= offers only Spanish ones. =cape-dict-file= accepts
  a function and calls it on every completion, so switching a
  buffer's language with =C-M-$= takes effect immediately, with no
  cache to invalidate. Note that =dabbrev-capf= deliberately stays
  language-agnostic: if a word is in a buffer you have open, you want
  to complete it whatever language it belongs to.
- eglot's own capf for code, added automatically in buffers where
  =eglot-ensure= runs (see the eglot configuration section).

=dabbrev-capf= and =cape-dict= are merged with =cape-capf-super= so
both contribute candidates to the same popup instead of the first
one shadowing the other.

#+begin_src emacs-lisp
  (use-package corfu
    :ensure t
    :init
    (global-corfu-mode)
    :custom
    (corfu-auto t)
    (corfu-auto-delay 0.4)
    (corfu-auto-prefix 3)
    (corfu-cycle t))

  (use-package cape
    :ensure t
    :init
    (require 'dabbrev)
    (defun my/cape-dict-build (dic-file out-file)
      "Cache a plain, one-word-per-line copy of hunspell DIC-FILE at OUT-FILE."
      (unless (file-exists-p out-file)
        (with-temp-buffer
          (insert-file-contents dic-file)
          (goto-char (point-min))
          (delete-region (point-min) (progn (forward-line 1) (point)))
          (while (re-search-forward "/.*$" nil t)
            (replace-match ""))
          (write-region (point-min) (point-max) out-file)))
      out-file)
    (defvar my-hunspell-dictionaries
      '(("en" . "/usr/share/hunspell/en_US.dic")
        ("es" . "/usr/share/hunspell/es_ES.dic"))
      "Hunspell .dic source per two-letter language code.")

    (defun my/cape-dict-files ()
      "Word lists for the current buffer's `jinx-languages'.
  Called by `cape-dict' on every completion, so switching the
  buffer's language with C-M-$ takes effect immediately."
      (let ((langs (split-string (or (bound-and-true-p jinx-languages) "en")
                                 nil t)))
        (or (delq nil
                  (mapcar (lambda (lang)
                            (when-let* ((dic (alist-get (substring lang 0 2)
                                                        my-hunspell-dictionaries
                                                        nil nil #'equal)))
                              (my/cape-dict-build
                               dic
                               (expand-file-name (concat "cape-dict-"
                                                         (file-name-base dic))
                                                 my-data-dir))))
                          langs))
            ;; Unknown language: fall back to English rather than to an
            ;; empty list, which would make cape-dict silently dead.
            (list (my/cape-dict-build
                   "/usr/share/hunspell/en_US.dic"
                   (expand-file-name "cape-dict-en_US" my-data-dir))))))

    (setq cape-dict-file #'my/cape-dict-files)
    (add-hook 'completion-at-point-functions
              (cape-capf-super #'dabbrev-capf #'cape-dict)))
#+end_src
