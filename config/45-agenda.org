#+title: Agenda — shared frame
#+property: header-args:emacs-lisp :tangle "45-agenda.el"
#+startup: overview

The agenda settings each environment establishes before its own views:
styling, category icons, which files are scanned, refiling and habits.

The two sets are deliberately still gated rather than merged.  They look
parallel but they are not the same: the icon alists cover different categories,
and the work environment does *not* skip DONE items the way the personal one
does (=org-agenda-skip-scheduled-if-done= is nil there).  Putting them adjacent
makes that visible; merging them would have silently changed how the work
agenda renders.

Things the work side is missing, should you want them: the DONE-skipping trio,
=org-agenda-tags-column=, =org-agenda-block-separator=, the breadcrumbs
separator, the time grid and the "now" line.

The custom agenda commands are large enough to warrant their own files;
see =46-agenda-personal.org= and =47-agenda-work.org=.

* org-super-agenda (both environments)
Declared here because both =46-agenda-personal= and =47-agenda-work= use it,
and each of those only loads in its own environment.  Where the groups come
from differs: home binds them inside its "a" command only, while work sets them
globally (in =47=).

#+begin_src emacs-lisp
  (use-package org-super-agenda
    :ensure t
    :config
    (org-super-agenda-mode 1))
#+end_src

Have some fancy icons for the categories.  =my/agenda-icon= builds one entry
from a category and an SVG in =my-agenda-icons-dir=; the work frame below uses
it too.
#+begin_src emacs-lisp
  (defun my/agenda-icon (category file)
    "An `org-agenda-category-icon-alist' entry showing FILE for CATEGORY.
FILE is relative to `my-agenda-icons-dir'."
    (list category (expand-file-name file my-agenda-icons-dir)
          nil nil :ascent 'center :mask 'heuristic))

  (when my-homeenvironment-p
    (setq org-agenda-category-icon-alist
          (list (my/agenda-icon "calendar"  "calendar.svg")
                (my/agenda-icon "tasks"     "check-square.svg")
                ;; the Inbox capture template sets CATEGORY: task (singular)
                (my/agenda-icon "task"      "check-square.svg")
                (my/agenda-icon "projects"  "list.svg")

** Get rid of the DONE tasks in the agenda view
We dont want the cluttering in our views. If a task is done, don't show it on the agenda view.
#+begin_src emacs-lisp
  (when my-homeenvironment-p
    (setq org-agenda-skip-scheduled-if-done t)
    (setq org-agenda-skip-deadline-if-done t)
    (setq org-agenda-skip-timestamp-if-done t)
    )
#+end_src

* Refile entries
This lets you choose refiling targets in heading depth of 9, and lets you get also the files in the same directory hierarchy.

#+begin_src emacs-lisp
  (when my-homeenvironment-p
    ;; all the targets
    (setq org-refile-targets `(
                               (org-agenda-files :maxlevel . 9)
                               ("referencias.org" :maxlevel . 9)
                               ("someday.org" :maxlevel . 9) ;; this is called someday.org now
                               (,(expand-file-name "retazos/ideas.org" my-escritura-dir) :maxlevel . 9)))

    (setq org-outline-path-complete-in-steps nil)         ; Refile in a single go
    ;;(setq org-refile-use-outline-path t)                  ; Show full paths for refiling
    (setq org-refile-use-outline-path 'file)                  ; Show full paths for refiling
    )
#+end_src

** Refile environment for work
Since this is a different environment, I also have to change this to refile things in a different way.

  (when my-workenvironment-p
      (setq org-refile-targets '(
                                (nil :maxlevel . 9)
                                (org-agenda-files :maxlevel . 9)
    			    (my-backlog-file :maxlevel . 9)
    			    (my-decisions-file :maxlevel . 2)))

      (setq org-outline-path-complete-in-steps nil)         ; Refile in a single go

    )
