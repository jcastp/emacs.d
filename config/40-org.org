* org-clock
Remap the org-clock-in to a better key binding.
#+begin_src emacs-lisp
  (defun my/org-set-clock ()
    "One-off function for `org-mode' task clocking.

  Behaviour:
   ,* When there is no running clock, start the clock for the item at point.
   ,* When there is already a running clock and `point' is at the item which is being clocked stop the corresponding clock.
   ,* When there is already a running clock but `point' is not at the item which is being clocked, stop the clock and restart it for item at `point'."
    (interactive)
    ;; org-clock is loaded lazily, on the first clock-in; the variables
    ;; below are void until then.
    (require 'org-clock)
    (let ((interrupting (and (not org-clock-resolving-clocks-due-to-idleness)
                             (org-clocking-p))))
      (if interrupting
          (if (save-excursion
                (org-back-to-heading t)
                (and (equal (marker-buffer org-clock-hd-marker)
                            (current-buffer))
                     (= (marker-position org-clock-hd-marker)
                        (point))
                     (equal org-clock-current-task (nth 4 (org-heading-components)))))
              (org-clock-out)
            (org-clock-in))
        (org-clock-in))))

  ;; keybindings
  (global-set-key (kbd "C-c C-x C-i") 'org-clock-in)
  (global-set-key (kbd "C-c C-x C-o") 'org-clock-out)
  (global-set-key (kbd "C-c C-x i") 'my/org-set-clock)
#+end_src

At work the clock is a measurement (see "Measuring time" in the work
=manual.org=), so a running clock has to survive an Emacs restart, and a
clock left running through a long absence has to be caught.

- =org-clock-persist= saves the running clock and the clock history on exit;
  on the next start Org asks whether to resume it.
- =org-clock-idle-time= is 60, not the usual 10–15: with no =x11idle= helper
  installed (and Emacs likely in a VM), Org can only see Emacs's own idle
  time, so a Teams call or browser work counts as "idle".  60 minutes still
  catches a clock left running over lunch or overnight without prompting in
  every meeting.

#+begin_src emacs-lisp
  (when my-workenvironment-p
    (setq org-clock-persist t
          org-clock-idle-time 60)
    (with-eval-after-load 'org
      (org-clock-persistence-insinuate)))
#+end_src

* org-pomodoro
A Pomodoro timer on top of org-clock: =M-x org-pomodoro= on a heading (or an
agenda line) clocks in to it for 25 minutes, then starts a 5-minute break, and
a 20-minute one every fourth time.  Each pomodoro leaves a normal =CLOCK:=
line, so clock tables see it.  Starting one clocks out whatever was running.

The timer lengths are the package defaults.  At home the writing environment
(writeroom) hides the mode line and its countdown, so the end of a pomodoro
is also a desktop notification.  The writing wrapper, =C-q w p=, is in
=60-writing=.

#+begin_src emacs-lisp
  (use-package org-pomodoro
    :commands org-pomodoro
    :config
    (when my-homeenvironment-p
      (setq alert-default-style 'notifications)))
#+end_src

    "Capture a note to the current buffer’s file, under the headline \"Notes\")."
    (interactive)
    ;; Make sure we are in an Org buffer.

** Wide tables
=global-visual-line-mode= (=10-ui=) wraps every long screen line, and Org
cannot wrap text inside a cell, so a table that is too wide breaks onto
several lines and loses its grid.  The fix is Org's own *width cookies*: a row
of =<N>= tells Org to show a column as its first N characters plus =…=.  The
file keeps the full text, and every exporter drops the cookie row.  Design
note: =20261125-orgmode-table.org=.

A table opens shrunk only if it has a cookie row; others are untouched.
#+begin_src emacs-lisp
  (setq org-startup-shrink-all-tables t)
#+end_src

=my/org-table-fit= (=C-q s f=) works the cookies out for the table at point.
It measures the window in pixels, divided by the =org-table= font's width,
because the writing presets draw tables in a bigger font than the one columns
are counted in (=writing-big=: 140 against 120).  Columns narrower than an
equal share keep their width; the wide ones split what is left.  It replaces
any existing cookie row, including one tuned by hand, and removes it when the
table already fits.  A numeric prefix (=C-u 75 C-q s f=) fits to that many
columns instead, e.g. the narrowest org-scribe mode.

Reading and editing the full text: =C-u C-u C-c TAB= expands the table,
=C-u C-c TAB= shrinks it back, =C-c TAB= toggles one column, and =C-c `= edits
one cell in its own wrapped buffer.  Typing into a shrunk cell expands its
column by itself.

#+begin_src emacs-lisp
  (defun my/org-table--available-width (&optional cols)
    "Columns of `org-table' text that fit on one screen line at point.
  COLS is the line width; by default it is measured in pixels, so a table
  face bigger than `default' (the writing presets) or a centred window is
  accounted for.  The table's indentation, org-indent's included, is taken off.
  The line numbers are taken off too: `window-body-width' still counts them
  (`window-max-chars-per-line' does not, but subtracts them in `default'
  columns, which is wrong when the table font is a different size)."
    (let* ((char (max 1 (window-font-width nil 'org-table)))
           (cols (or cols (/ (- (window-body-width nil t)
                                (line-number-display-width t))
                             char)))
           (prefix (progn
                     ;; org-indent adds its prefixes from an idle timer, so a
                     ;; buffer opened a moment ago may not have them yet
                     (when (and (bound-and-true-p org-indent-mode)
                                (not (get-text-property (point) 'line-prefix)))
                       (org-indent-add-properties (line-beginning-position)
                                                  (line-end-position)))
                     (get-text-property (point) 'line-prefix)))
           (indent (+ (current-indentation)
                      (if (stringp prefix) (string-width prefix) 0))))
      (- cols indent 1)))                 ; 1: room for the wrap glyph

  (defun my/org-table--cookie-row-p (row)
    "Non-nil when ROW (a list of strings) holds only width cookies or blanks."
    (and (listp row)
         (cl-some (lambda (c) (string-match-p "\\`<[lrc]?[0-9]*>\\'" c)) row)
         (cl-every (lambda (c) (or (string-empty-p c)
                                   (string-match-p "\\`<[lrc]?[0-9]*>\\'" c)))
                   row)))

  (defun my/org-table--fit-widths (natural budget)
    "Return a width per column (nil = leave it alone) so NATURAL fits BUDGET.
  Water-filling: columns narrower than an equal share keep their width, the
  rest share what is left.  A shrunk column costs one extra character for
  `org-table-shrunk-column-indicator'."
    (let ((n (length natural)))
      (if (<= (apply #'+ natural) budget)
          (make-list n nil)
        (let ((wide (number-sequence 0 (1- n)))
              (left budget)
              (changed t))
          ;; drop columns that fit in their share, until stable
          (while changed
            (setq changed nil)
            (let ((share (/ (- left (length wide)) (max 1 (length wide)))))
              (dolist (i wide)
                (when (<= (nth i natural) share)
                  (setq wide (delq i wide)
                        left (- left (nth i natural))
                        changed t)))))
          (let ((share (max 3 (/ (- left (length wide)) (max 1 (length wide))))))
            (cl-loop for i below n
                     collect (and (memq i wide) share)))))))

  (defun my/org-table--column-widths ()
    "Visible width of each column of the aligned table at point, or nil.
  Read from the table's first hline: Org pads every column to its *visible*
  width, so the dashes are that width plus 2, and text Org hides (emphasis
  markers, link targets) is not counted.  Nil when the table has no hline."
    (save-excursion
      (goto-char (org-table-begin))
      (let ((end (org-table-end)))
        (while (and (< (point) end) (not (org-at-table-hline-p)))
          (forward-line))
        (when (< (point) end)
          (mapcar (lambda (dashes) (max 1 (- (length dashes) 2)))
                  (split-string (buffer-substring-no-properties
                                 (line-beginning-position) (line-end-position))
                                "[ \t]*[|+][ \t]*" t))))))

  (defun my/org-table-fit (&optional width)
    "Shrink the wide columns of the table at point to fit the window.
  Writes width cookies (a row of <N>) into the table, which Org shows
  shrunk and every exporter drops.  WIDTH, or a numeric prefix, overrides
  the measured window width.  Run it again after changing font preset or
  window layout; a table that already fits loses its cookie row."
    (interactive "P")
    (unless (org-at-table-p) (user-error "Not in an Org table"))
    (when (org-at-table.el-p) (user-error "A table.el table: nothing to fit"))
    ;; Realigning rewrites the table, so `save-excursion' would lose the
    ;; cell; come back to it by row and column instead.
    (let ((row (count-lines (org-table-begin) (line-beginning-position)))
          (col (org-table-current-column))
          (shift 0))
      (goto-char (org-table-begin))
      (let* ((avail (my/org-table--available-width
                     (and width (prefix-numeric-value width))))
             (rows (org-table-to-lisp))
             (old (cl-position-if #'my/org-table--cookie-row-p rows))
             (data (cl-remove-if (lambda (r) (or (eq r 'hline)
                                                 (my/org-table--cookie-row-p r)))
                                 rows))
             (ncol (apply #'max (mapcar #'length data)))
             natural budget widths)
        (org-table-expand)
        ;; remove the old cookie row, if any (ROWS counts hlines as rows too)
        (when old
          (goto-char (org-table-begin))
          (forward-line old)
          (delete-region (line-beginning-position) (1+ (line-end-position)))
          (when (< old row) (cl-decf shift)))
        (goto-char (org-table-begin))
        (org-table-align)
        ;; Visible widths from the aligned table; without an hline, fall back
        ;; to the raw text, which counts hidden markup and so errs narrow.
        (setq natural
              (or (my/org-table--column-widths)
                  (cl-loop for i below ncol
                           collect (apply #'max 1
                                          (mapcar (lambda (r)
                                                    (string-width (or (nth i r) "")))
                                                  data))))
              ;; "| " before each cell, " " after it, and the closing "|"
              budget (- avail (* 3 (length natural)) 1)
              widths (my/org-table--fit-widths natural budget))
        (goto-char (org-table-begin))
        (if (not (cl-some #'identity widths))
            (progn (org-table-align)
                   (message "Table fits in %d columns; no cookies needed" avail))
          (insert (make-string (current-indentation) ?\s)
                  "|" (mapconcat (lambda (w) (if w (format "<%d>" w) ""))
                                 widths "|")
                  "|\n")
          (cl-incf shift)
          (forward-line -1)
          (org-table-align)
          (org-table-shrink)
          (message "Table fitted to %d columns" avail)))
      ;; on the old cookie row itself, land on the first row instead
      (goto-char (org-table-begin))
      (forward-line (max 0 (+ row shift)))
      (when (org-at-table-p) (org-table-goto-column col))))
#+end_src

    (defun my/blog-capture-template ()
      "Return an ox-hugo subtree capture template for a new blog draft."
      (let* ((title (read-from-minibuffer "Post title: "))
             (slug  (replace-regexp-in-string
                     "[^a-z0-9]+" "-"

** Custom work capture templates
As work is different from home, I need specific templates.

#+begin_src emacs-lisp
  (when my-workenvironment-p
    ;; (defvar my/direct-reports nil
    ;;   "List of direct reports for 1:1 capture templates. Loaded from my-data-dir.")

    (defvar my/capture-person nil
      "Employee name selected during org-capture, shared between target and template body.")

    (defun my/capture-goto-person ()
      "Capture target: ask for a direct report and go to their heading in `my-people-file'."
      (let ((person (completing-read "Employee: " my/direct-reports)))
        (setq my/capture-person person)
        (find-file my-people-file)
        (goto-char (org-find-olp (list my-people-file person)))))

    (defun my/capture-optional-deadline ()
      "Ask whether a real deadline was agreed; return a DEADLINE line or \"\".
    A deadline is only for a date with a real consequence (see the work
    manual.org), so a 1:1 commitment gets one only when it was agreed."
      (if (y-or-n-p "Was a real deadline agreed? ")
          (concat "\n    DEADLINE: "
                  (with-temp-buffer
                    (org-insert-time-stamp (org-read-date nil t))))
        ""))

    ;; Work owns the full template list, in the order the menu shows it.
    ;; One literal list rather than `add-to-list', which prepends and so
    ;; reversed the menu.  Targets given as bare variables (`my-work-file')
    ;; are resolved by org-capture when the template runs.
    (setq org-capture-templates
          `(("i" "Inbox (work)" entry
             (file+headline my-work-file "Inbox")
             "** TODO %? %^g")

            ;; people meetings
            ("p" "1:1 meeting" entry
             (function my/capture-goto-person)
             "** %T - follow-up\n*** Notes\n%?\n*** Actions\n*** Questions\n"
             :jump-to-captured t)

            ;; And a quick action capture from within a 1:1 note:
            ("P" "People action item" entry
             (function my/capture-goto-person)
             "*** TODO [%(identity my/capture-person)] %<%Y-%m-%d %a %H:%M> %? :people:%(downcase my/capture-person):%(my/capture-optional-deadline)"
             :jump-to-captured t)

            ;; Tier 1 -- fast capture. Two prompts, usable mid-meeting.
            ("D" "Decision (fast)" entry
             (file+headline my-decisions-file "Inbox")
             ,(concat "** %?\n"
                      ":PROPERTIES:\n"
                      ":DECIDED:  %U\n"
                      ":STATUS:   accepted\n"
                      ":SOURCE:   %^{Where|meeting|teams|email|1:1|solo}\n"
                      ":END:\n")
             :empty-lines-after 1)

            ;; Tier 2 -- full record. Used when promoting at review, or straight
            ;; away for a decision that is clearly hard to reverse.
            ("R" "Decision (full record)" entry
             (file+headline my-decisions-file "Decisions")
             ,(concat "** %^{Decision}\n"
                      ":PROPERTIES:\n"
                      ":DECIDED:  %U\n"
                      ":STATUS:   accepted\n"
                      ":DECIDERS: %^{Deciders}\n"
                      ":INFORMED: %^{Informed}\n"
                      ":SOURCE:   %^{Where|meeting|teams|email|1:1|solo}\n"
                      ":REVERSIBILITY: %^{Reversibility|easy|hard}\n"
                      ":END:\n"
                      "In the context of %^{Context}, facing %^{Concern}, "
                      "we decided for %\\1 and neglected %^{Rejected}, "
                      "accepting %^{Downside}.\n%?\n")
             :empty-lines-after 1)

            ;; Disabled: work_meetings.org is history only.  New meetings are
            ;; roam nodes: C-c n c, then m (see 50-org-roam).
            ))
    )
#+end_src
