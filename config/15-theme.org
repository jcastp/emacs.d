#+startup: overview

Theme packages, the light/dark rotation, and every fontaine preset.

fontaine is declared once.  Each environment sets =fontaine-presets= wholesale,
and the two tables sit next to each other so the difference is visible.

Nothing here recolours =hl-line= or the org faces.  =10-ui= and =17-org-style=
each follow =enable-theme-functions=, so any theme enabled here, or anywhere
else, recolours them without being asked.

* Font setup
Look at this https://idiocy.org/emacs-fonts-and-fontsets.html
** fonts
The fonts belong to the fontaine presets below: =default=, =fixed-pitch= and
=variable-pitch= are set only there.  Do not set them in the =user= theme as
well: it outranks fontaine's every time a theme is enabled, so every theme
change would silently reset the preset.

Assign the variable font to prose mode:
#+begin_src emacs-lisp
  (add-hook 'text-mode-hook 'variable-pitch-mode)
  (add-hook 'org-mode-hook 'variable-pitch-mode)
#+end_src

Use fixed font for code blocks and other non prose blocks.

The org faces' colours and sizes are in =17-org-style=.  What is here is only
about *fonts*: keeping
comments and org's own structural faces on the fixed-pitch family so they do not
fall back to whatever font happens to supply an italic glyph.

#+begin_src emacs-lisp
  (my/set-face-specs
   ;; keep comments (in code blocks and elsewhere) on the fixed-pitch font,
   ;; instead of falling back to whatever font provides the italic glyph
   '(font-lock-comment-face    ((t (:inherit fixed-pitch))))
   '(font-lock-comment-delimiter-face ((t (:inherit fixed-pitch))))
   '(org-verbatim              ((t (:inherit (shadow fixed-pitch)))))
   '(org-indent                ((t (:inherit (org-hide fixed-pitch)))))
   '(org-table                 ((t (:inherit (org-hide fixed-pitch)))))
   ;; check if this works
   '(org-comment               ((t (:inherit (org-hide fixed-pitch) :height 0.8)))))
#+end_src

* Themes
** Establish the default theme
Two rotations, dark and clear.  =my/theme-next= takes the first theme of one and
moves it to the back, so repeated calls walk through the whole list.  Startup
takes the next dark theme (or the next clear one, if =my-theme-start-dark-p= is
nil), and =C-c 0= takes the next theme of the /other/ rotation.

The lists are declared with =defvar= but set with =setq=, so =C-c r r= (reload)
resets both rotations rather than resuming them.
#+begin_src emacs-lisp
  (when my-homeenvironment-p
    (defvar my/themes-dark nil "Dark themes, in rotation order.")
    (defvar my/themes-clear nil "Clear themes, in rotation order.")
    (setq my/themes-dark '(ef-deuteranopia-dark
                           modus-vivendi-tinted))
    (setq my/themes-clear '(leuven
                            ef-deuteranopia-light
                            modus-operandi))

    ;; t starts on the dark rotation, nil on the clear one
    (defvar my-theme-start-dark-p t
      "Whether startup applies the first dark theme or the first clear one.")

    (defun my/theme-next (rotation)
      "Return the first theme of the list in ROTATION, moving it to the back."
      (let ((theme (car (symbol-value rotation))))
        (set rotation (append (cdr (symbol-value rotation)) (list theme)))
        theme))

    (load-theme (my/theme-next (if my-theme-start-dark-p
                                   'my/themes-dark
                                 'my/themes-clear))
                t))
#+end_src

** Toggle light and dark themes
#+begin_src emacs-lisp
  (when my-homeenvironment-p
    (defun my/theme-changer ()
      "Switch between dark and clear, taking the next theme of the other rotation."
      (interactive)
      (let ((theme (my/theme-next (if (my/theme-dark-p)
                                      'my/themes-clear
                                    'my/themes-dark))))
        (consult-theme theme)
        (message "The theme applied is %s" theme)))

    (global-set-key (kbd "C-c 0") 'my/theme-changer))
#+end_src
  

The presets list only what makes each one different.  Everything else comes
from the shared =t= preset below, which fontaine merges into every preset.  Both
environments append it to their own list.

Three things about it are load-bearing:
- =:fixed-pitch-serif-family "Monospace"= is what fontaine falls back to when
  there is *no* =t= preset.  Having one switches that fallback off, so it is
  spelled out.
- =:line-spacing 0= stays explicit: a preset without it sets =line-spacing= to
  nil.
- An explicit nil in a preset still shadows =t= (=editing='s
  =:fixed-pitch-weight nil=), but a nil that means "unset" can simply be left
  out, which is why there is no =:bold-family nil= anywhere.

#+begin_src emacs-lisp
  (defvar my-fontaine-shared-preset
    '(t
      :default-family "Aporetic Sans Mono"
      :default-weight normal
      :default-height 120
      :fixed-pitch-family "Aporetic Sans Mono"
      :fixed-pitch-weight Light
      :fixed-pitch-height 110
      :fixed-pitch-serif-family "Monospace"
      :variable-pitch-family "Aporetic Sans"
      :variable-pitch-weight Medium
      :variable-pitch-height 140
      :bold-weight bold
      :italic-family "Aporetic Sans"
      :italic-slant italic
      :line-spacing 0)
    "The fontaine `t' preset: the fallback for every property a preset omits.")

  (when my-homeenvironment-p
    (setq fontaine-presets
          (append
           '(;; Hack for prose and code alike
             (hack
              :default-family "Hack"
              :default-weight light
              :fixed-pitch-family "Hack"
              :variable-pitch-family "Hack"
              :variable-pitch-weight light
              :variable-pitch-height 110
              :italic-family "Hack")
             ;; daily operations: exactly the shared preset
             (regular)
             (regular-aporetic-mono
              :default-height 110
              :variable-pitch-family "Aporetic Sans Mono"
              :variable-pitch-height 110
              :italic-family "Aporetic Sans Mono")
             ;; bigger variable-width face, so I can focus on it
             (writing
              :default-family "ETBembo"
              :default-height 150
              :fixed-pitch-height 120
              :variable-pitch-family "ETBembo"
              :variable-pitch-height 150
              :italic-family "ETBembo"
              :line-spacing 1)
             (writing-big
              :inherit writing
              :default-height 180
              :fixed-pitch-height 140
              :variable-pitch-height 180)
             ;; a different variable-width face for a different view when editing
             (editing
              :default-height 130
              :fixed-pitch-weight nil
              :variable-pitch-family "Gentium"
              :variable-pitch-weight normal
              :variable-pitch-height 150
              :italic-family "Gentium"
              :line-spacing 1))
           (list my-fontaine-shared-preset)))

    (fontaine-set-preset 'hack))
#+end_src

* Work theme and presets
The =hl-line= foreground and the org faces follow from =enable-theme-functions=,
like at home.  The cursor, the fringe and the title are set by hand after the
theme, so they only survive until the next theme change.

#+begin_src emacs-lisp
  (when my-workenvironment-p
    (load-theme 'modus-operandi-deuteranopia t)
    (set-cursor-color "#00008B")
    (set-face-background 'fringe "#00008B")
    (setq-default frame-title-format "[WORK] %b - (%f)"))
#+end_src

#+begin_src emacs-lisp
  (when my-workenvironment-p
    (setq fontaine-presets
          (append
           '((hack-big
              :default-family "Hack"
              :default-weight light
              :default-height 140
              :fixed-pitch-family "Hack"
              :fixed-pitch-height 140
              :variable-pitch-family "Hack"
              :variable-pitch-weight light
              :variable-pitch-height 140
              :italic-family "Hack")
             ;; daily operations: exactly the shared preset
             (regular)
             ;; font for work
             (work
              :default-height 140
              :fixed-pitch-height 120))
           (list my-fontaine-shared-preset)))

    (fontaine-set-preset 'work))
#+end_src

* Keymap entries
The =C-q t= sub-map: fonts, themes and the visual fill column.
#+begin_src emacs-lisp
  (let ((themes (my/key-define-submap "t" "themes and fonts")))
    (my/key-define "f" "font preset"  #'fontaine-set-preset       themes)
    (my/key-define "t" "theme"        #'consult-theme             themes)
    (my/key-define "v" "fill column"  #'visual-fill-column-mode   themes))
#+end_src
