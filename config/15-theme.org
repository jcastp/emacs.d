#+property: header-args:emacs-lisp :tangle "15-theme.el"
#+startup: overview

Theme packages, the light/dark rotation, and every fontaine preset.

fontaine is declared once.  Each environment sets =fontaine-presets= wholesale,
and the two tables sit next to each other so the difference is visible.

Nothing here recolours =hl-line= or the org faces.  =10-ui= and =17-org-style=
each follow =enable-theme-functions=, so any theme enabled here, or anywhere
else, recolours them without being asked.

* Font setup
Look at this https://idiocy.org/emacs-fonts-and-fontsets.html
** fonts
The fonts belong to the fontaine presets below: =default=, =fixed-pitch= and
=variable-pitch= are set only there.  Do not set them in the =user= theme as
well: it outranks fontaine's every time a theme is enabled, so every theme
change would silently reset the preset.

Assign the variable font to prose mode:
#+begin_src emacs-lisp
  (add-hook 'text-mode-hook 'variable-pitch-mode)
  (add-hook 'org-mode-hook 'variable-pitch-mode)
#+end_src

Use fixed font for code blocks and other non prose blocks.

The org faces' colours and sizes are in =17-org-style=.  What is here is only
about *fonts*: keeping
comments and org's own structural faces on the fixed-pitch family so they do not
fall back to whatever font happens to supply an italic glyph.

#+begin_src emacs-lisp
  (my/set-face-specs
   ;; keep comments (in code blocks and elsewhere) on the fixed-pitch font,
   ;; instead of falling back to whatever font provides the italic glyph
   '(font-lock-comment-face    ((t (:inherit fixed-pitch))))
   '(font-lock-comment-delimiter-face ((t (:inherit fixed-pitch))))
   '(org-verbatim              ((t (:inherit (shadow fixed-pitch)))))
   '(org-indent                ((t (:inherit (org-hide fixed-pitch)))))
   '(org-table                 ((t (:inherit (org-hide fixed-pitch)))))
   ;; check if this works
   '(org-comment               ((t (:inherit (org-hide fixed-pitch) :height 0.8)))))
#+end_src

* Themes
** Establish the default theme
Define some variables with the dark and clear themes, and a variable to control if the current theme is dark or clear.
Also, rotate the list of themes applied.
#+begin_src emacs-lisp
  (when my-homeenvironment-p
    ;; define the lists of clear and dark themes
    (setq my/themes-dark '(ef-deuteranopia-dark
    		       modus-vivendi-tinted))
    (setq my/themes-clear '(leuven
    			ef-deuteranopia-light
    			modus-operandi))

    ;; t starts on the dark rotation, nil on the clear one
    (defvar my-theme-start-dark-p t
      "Whether startup applies the first dark theme or the first clear one.")

    ;; define a function to rotate a list. Custom, yes, I know it could be done better.
    (defun my/rotate-list (list)
      "Rotate the elements of LIST by one position, moving the first element to the end, and return the new list."
      (if (null list)
          ;; if block
          ;; if the list is empty, returns an empty list
          '()
        ;; else block
        ;; rotates the list
        (append (cdr list) (list (car list)))))

    ;; load the first theme of the chosen rotation, and send it to the back
    ;; of its list so that C-c 0 moves on to the next one
    (if my-theme-start-dark-p
        (progn
          (load-theme (car my/themes-dark) t)
          (setq my/themes-dark (my/rotate-list my/themes-dark)))
      (load-theme (car my/themes-clear) t)
      (setq my/themes-clear (my/rotate-list my/themes-clear)))
    )
#+end_src

** Toggle light and dark themes
Function to change between dark and clear themes, based on past variables.
#+begin_src emacs-lisp
  (when my-homeenvironment-p
    (defun my/theme-changer ()
      "Changes themes between clear and dark ones."
      (interactive)
      ;; since we want to change from dark to clear and viceversa, we swap the logic
      (if (not (my/theme-dark-p))
          ;; this loads the dark theme
          (progn
            (consult-theme (car my/themes-dark))
            (message "The theme applied is %s" (car my/themes-dark))
            ;; rotate the list
            (setq my/themes-dark (my/rotate-list my/themes-dark)))
        ;; else block (clear theme)
        (progn
          (consult-theme (car my/themes-clear))
          (message "The theme applied is %s" (car my/themes-clear))
          ;; rotate the list
          (setq my/themes-clear (my/rotate-list my/themes-clear)))))

    (global-set-key (kbd "C-c 0") 'my/theme-changer)
    )
#+end_src

like at home.  The cursor, the fringe and the title are set by hand after the
theme, so they only survive until the next theme change.

  (when my-workenvironment-p

    (set-cursor-color "#00008B")

* Keymap entries
The =C-q t= sub-map: fonts, themes and the visual fill column.
#+begin_src emacs-lisp
  (let ((themes (my/key-define-submap "t" "themes and fonts")))
    (my/key-define "f" "font preset"  #'fontaine-set-preset       themes)
    (my/key-define "t" "theme"        #'consult-theme             themes)
    (my/key-define "v" "fill column"  #'visual-fill-column-mode   themes))
#+end_src
